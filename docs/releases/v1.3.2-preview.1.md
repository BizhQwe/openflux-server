# OpenFlux Server v1.3.2-preview.1

Предварительный релиз OpenFlux Server v1.3.2-preview.1 с исправлением установки на роутеры (Keenetic, Padavan, OpenWrt), оптимизацией службы Entware и поддержкой ключа полной деинсталляции `--uninstall`.

### 🚀 Что нового и исправлено:

1. **Исправление ошибки `read-only file system` на Keenetic, Padavan и встраиваемых Linux**:
   - На прошивках роутеров с SquashFS каталоги `/usr/local` и `/usr` защищены от записи (RO). В режиме Entware регистрация исполняемого файла CLI теперь производится строго в `/opt/bin/openflux`.
   - Вспомогательная регистрация псевдонимов (`registerAliases`) переведена в отказоустойчивый режим: ошибка создания симлинков в read-only путях больше не прерывает установку, если хотя бы один рабочий путь успешно зарегистрирован.

2. **Автоматический запуск и управление службой на роутерах**:
   - Устранена ошибка, из-за которой служба Entware `/opt/etc/init.d/S99openflux` не запускалась автоматически после завершения работы установщика.
   - Добавлен переносимый fallback на случай отсутствия утилиты `nohup` в минимальных образах Entware (`$DAEMON ... </dev/null &`).
   - Синхронизировано переключение автозапуска (`chmod 0755` при включении, `chmod 0644` при выключении).
   - Добавлена встроенная поддержка системного менеджера OpenWrt `procd` (`/etc/init.d/openflux`) с автоматическим контролем процесса и перезапуском при сбоях.

3. **Полная поддержка ключей деинсталляции `--uninstall` (`-u`, `-y`)**:
   - В скрипты загрузки `install-entware.sh` и `install.sh` добавлен быстрый обработчик `--uninstall`, `uninstall` и `-u`: система корректно и бесследно удаляется без повторной загрузки установочного архива.
   - В бинарном установщике поддержаны флаги `--uninstall`, `-u` и `-y` (`--yes`), а также подкоманда `uninstall`.
   - В CLI `openflux` добавлен короткий псевдоним `-u` для команды деинсталляции.

4. **Гибкая загрузка конкретных версий и pre-release сборок**:
   - Скрипты `install-entware.sh` и `install.sh` поддерживают переменную окружения `OPENFLUX_TAG`, позволяющую устанавливать pre-release и тестовые версии (например, `OPENFLUX_TAG=v1.3.2-preview.1`).
