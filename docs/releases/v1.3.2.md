# OpenFlux Server v1.3.2

Полноценный релиз OpenFlux Server v1.3.2 с нативной поддержкой роутеров (Keenetic, Padavan, OpenWrt), защитой от Read-Only файловых систем, автоматической адаптацией кодировки для VGA-консолей и оптимизацией памяти.

### 🚀 Что нового и исправлено:

1. **Установка через `curl` и пошаговые инструкции**:
   - Для установки сервера требуется утилита `curl`. В документацию и руководство добавлены чёткие пошаговые команды предварительной установки `curl` и корневых сертификатов (`opkg update && opkg install curl ca-certificates` для OpenWrt/Entware, `apt install -y curl` для Linux).
   - В скриптах установки дополнительно реализован резервный fallback-механизм загрузки (на случай наличия `wget` / `uclient-fetch`) и поддержка проверки контрольных сумм через `sha256sum`, `shasum` или `openssl`.

2. **Полная совместимость с Read-Only (RO) файловыми системами роутеров**:
   - На прошивках Keenetic, Padavan и SquashFS-образах OpenWrt каталоги `/usr/local` и `/usr` защищены от записи.
   - Регистрация симлинков CLI в `__path` теперь использует только доступные для записи каталоги: `/opt/bin/openflux` (для Entware/роутеров) и fallback в `/usr/bin/openflux`, полностью предотвращая ошибку `mkdir /usr/local/bin: read-only file system`.

3. **Оптимизация использования дискового пространства**:
   - Временные файлы загрузки инсталлятора теперь размещаются в `/tmp` (в оперативной памяти `tmpfs`), что исключает ошибку `no space left on device` на роутерах с небольшим объёмом системного раздела флеш-памяти.

4. **Автоматическая адаптация кодировки (исправление черных квадратов `■`)**:
   - Реализована функция `ConsoleSupportsCyrillic()` для CLI и установщика.
   - В виртуальных консолях Linux (VGA монитор, `/dev/tty1`, терминалы без загруженных кириллических шрифтов) интерфейс автоматически переключается на чистый английский язык, устраняя артефакты `■■■■■`. В SSH-терминалах с UTF-8 сохраняется полноценный русский язык.

5. **Надёжная остановка службы и деинсталляция**:
   - Таймаут ожидания корректного завершения веб-сервера и фоновых туннелей в `c.wait()` увеличен с 10 до 25 секунд.
   - Добавлен fallback при остановке службы на роутерах: при превышении таймаута оставшиеся процессы завершаются принудительно, гарантируя, что `openflux uninstall` завершается успешно без сбоев.
