# OpenFlux Server v1.3.2-preview.2

Предварительный релиз OpenFlux Server v1.3.2-preview.2 с автоматической адаптацией кодировки для виртуальных консолей роутеров (VGA/tty без кириллических шрифтов) и сквозной верификацией всех сценариев деинсталляции.

### 🚀 Что нового и исправлено:

1. **Автоматическая адаптация кодировки (исправление отображения черных квадратов `■`)**:
   - В ядре виртуальных консолей Linux (`TERM=linux`, `/dev/tty0`..`tty63`, VGA монитор роутера/ВМ) отсутствует кириллический растровый шрифт (поддерживается только базовый ASCII/CP437). Ранее вывод кириллицы приводил к заполнению строк черными квадратами (`■■■■■: openflux <■■■■■■■>`).
   - Добавлена функция детекции возможностей активной консоли `ConsoleSupportsCyrillic()` в CLI и установщике.
   - При выводе в системные консоли без поддержки кириллицы интерфейс автоматически переключается на чистый английский язык, гарантируя 100% читаемость всех команд, меню справки и статуса.
   - В терминалах SSH (`TERM=xterm`, `putty`, `xterm-256color`) кириллица отображается в полном объёме при выборе русского языка.
   - В Windows консолях при запуске принудительно активируется кодовая страница UTF-8 (CP 65001).

2. **Сквозная верификация всех сценариев деинсталляции (`--uninstall`, `-u`, `-y`)**:
   - **Сценарий 1 (CLI с ключом `-y`)**: `openflux uninstall -y` и `openflux --uninstall -y` гарантированно останавливают все службы и фоновые процессы, удаляют каталог установки `/opt/openflux-server`, симлинки (`/opt/bin/openflux`, `/usr/local/bin/openflux`) и скрипты служб.
   - **Сценарий 2 (Интерактивный CLI)**: `openflux uninstall` запрашивает подтверждение удаления и очистки портов брандмауэра; при ответе `n` система остаётся в неизменном состоянии.
   - **Сценарий 3 (Бинарный установщик)**: Запуск бинарника установщика с флагами `--uninstall -y` или `-u -y` полностью очищает установку.
   - **Сценарий 4 (Скрипт Entware)**: Скрипт `install-entware.sh --uninstall` (и `-u`) мгновенно останавливает службу `/opt/etc/init.d/S99openflux`, очищает PID, логи и удаляет файлы без загрузки архивов.
   - **Сценарий 5 (Скрипт Linux)**: Скрипт `install.sh --uninstall` (и `-u`) очищает службы systemd/procd, закрывает порты в брандмауэрах (UFW, firewalld, iptables) и удаляет данные.
   - **Сценарий 6 (Служба OpenWrt procd)**: Нативная служба OpenWrt `/etc/init.d/openflux` корректно останавливается, деактивируется (`disable` с удалением симлинков в `/etc/rc.d/`) и полностью удаляется.

3. **Скрипты загрузки**:
   - Начальные информационные сообщения скриптов установки переведены на универсальный ASCII-текст, что предотвращает артефакты кодировки на любых устройствах до запуска установщика.
