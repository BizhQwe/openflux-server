# OpenFlux Server v1.3.0

Мажорное обновление OpenFlux Server v1.3.0 с автоматической настройкой сетевых экранов, UPnP-пробросом портов и обновленной поддержкой клиентов:

- **Автоматическое открытие портов в системных брандмауэрах**:
  - **Linux**: при установке и смене портов автоматически настраиваются правила в `UFW`, `firewalld` и `iptables` / `ip6tables` для порта панели (5000), а также портов 80 и 443 для Let's Encrypt и HTTPS.
  - **Windows**: автоматически создаются правила входящего трафика в Windows Defender Firewall через `netsh advfirewall` для портов и исполняемого файла панели.
- **Автоматический проброс портов на роутерах (UPnP IGD)**:
  - Реализован встроенный UPnP/SSDP-клиент: при старте сервера или выпуске SSL-сертификата сервер опрашивает домашний/офисный роутер и автоматически пробрасывает необходимые порты на локальный IP-адрес хоста.
- **Официальный Android-клиент**:
  - Добавлена интеграция и рекомендации официального Android-клиента [**OpenFlux Android**](https://github.com/BizhQwe/openflux-android) с поддержкой быстрого импорта туннелей по QR-коду и схемам `openflux://`.
- **Автоматическая очистка правил брандмауэра**:
  - При удалении сервера (`openflux uninstall` или `install.sh --uninstall`) созданные правила сетевого экрана корректно удаляются.

### Быстрая установка

**Linux:**
```bash
curl -sSL https://raw.githubusercontent.com/BizhQwe/openflux-server/main/scripts/install.sh | sudo bash
```

**Windows (PowerShell от имени Администратора):**
```powershell
irm https://raw.githubusercontent.com/BizhQwe/openflux-server/main/scripts/install.ps1 | iex
```
