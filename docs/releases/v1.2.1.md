# OpenFlux Server v1.2.1

Точечное обновление веб-панели управления туннелями OpenFlux Server v1.2.1:
- **Удаление транспорта Mixed**: транспорт `mixed` («Mixed / Striped») удален из интерфейса веб-панели (карточка выбора транспорта и опция селектора в диалоге создания/редактирования туннеля), так как данный тип не поддерживается официальными клиентами OpenFlux Android и Desktop.
- **Оптимизация формы настроек туннеля**: поле ввода «Исходящий SOCKS5-прокси (L4)» вынесено из двухколоночной сетки в отдельную полноразмерную строку формы и теперь занимает всю ширину модального окна. Скрытый блок настройки количества каналов (`group-lanes`) отделен выше.
- **Совместимость данных**: сохранена возможность работы с ранее сохраненными конфигурациями и обратная совместимость парсинга.

### Быстрая установка

**Linux:**
```bash
curl -sSL https://raw.githubusercontent.com/BizhQwe/openflux-server/main/scripts/install.sh | sudo bash
```

**Windows (PowerShell от имени Администратора):**
```powershell
irm https://raw.githubusercontent.com/BizhQwe/openflux-server/main/scripts/install.ps1 | iex
```
