# OpenFlux Server v1.2.0

Крупное обновление OpenFlux Server v1.2.0: интеграция новейшего ядра OpenFlux v0.17.1, ребрендинг в единый OpenFlux Server, каноничная Go-архитектура, улучшенное управление безопасностью веб-панели и надёжное бесшовное обновление службы.

### Быстрая установка

**Linux:**
```bash
curl -sSL https://raw.githubusercontent.com/BizhQwe/openflux-server/main/scripts/install.sh | sudo bash
```

**Windows (PowerShell от имени Администратора):**
```powershell
irm https://raw.githubusercontent.com/BizhQwe/openflux-server/main/scripts/install.ps1 | iex
```

### Что нового:

#### 1. Обновление ядра OpenFlux до v0.17.1
- **Telemost SFU**: размер слота по умолчанию повышен до Full HD (1920×1080) с ростом пропускной способности до 2.44x; добавлены параметры `slot_w` и `slot_h` для точной настройки разрешения видеокадра.
- **Защита аккаунтов (`--refuse-peer-login`)**: опция туннеля, запрещающая передачу клиентских cookies и данных авторизации серверу для исключения риска перехвата и подмены учётных записей.
- **Адаптивный MTU и согласование кадров**: несущие динамически объявляют `CarrierMTU`, интерфейс туннеля и WebRTC/SCTP автоматически подстраивают размеры пакетов без фрагментации.
- **Carrier Pinning**: возможность принудительной фиксации конкретной несущей в обход стандартного алгоритма приоритетов.
- **Оптимизация Avito ShareDB**: регистрация виртуальных комнат, обновленный User-Agent для предотвращения ошибок 403, скоординированный экспоненциальный backoff при лимитах 429.
- **Direct-транспорт**: увеличенные до 4 МиБ TCP-буферы передачи, оптимизированный алгоритм контроля перегрузок Reno и мгновенная обработка соединений.
- **Context Pinning**: единый детерминированный контекст KDF по умолчанию с сохранением обратной совместимости для старых клиентов.

#### 2. Ребрендинг и унификация (OpenFlux Server)
- Проект полностью переведён на лаконичное имя **OpenFlux Server** (отказ от маркировки Zen).
- Переименованы исполняемые файлы (`openflux-server-web`, `openflux-server-cli`, `openflux-server-core`), системные службы (systemd `openflux-server.service`, планировщик Windows `OpenFluxServer`) и пути данных.
- Обновлён визуальный стиль веб-панели: убран шильдик Zen, актуализирован логотип и локализация.
- Добавлена полная обратная совместимость: установщик автоматически мигрирует и зачищает устаревшие службы и бинарники Zen Server, сохраняя конфигурации и токены сессий.

#### 3. Реструктуризация кодовой базы по стандартам Go
- Структура каталогов приведена к каноничному виду: `src/cli`, `src/core`, `src/installer`, `src/web`.
- Обновлены `go.work`, все модули `go.mod`, сборочные скрипты (`build.sh`, `build.ps1`, `package-release.*`) и пайплайны GitHub Actions CI.

#### 4. Обновление веб-панели и безопасность настроек
- **Собственный секретный путь**: в панели настроек добавлен отдельный блок управления секретным URL с возможностью ввода произвольного пути вручную, кнопкой моментальной генерации и собственной кнопкой «Применить».
- **Бесшовная смена пути**: при изменении секретного пути автоматически перевыпускается авторизационная сессия и выполняется редирект на новый адрес без необходимости повторного ввода пароля.
- **Очистка настроек сети**: кнопка размещения переименована в лаконичное «Применить», убрано избыточное поле подсетей LAN.

#### 5. Исправления установщика и совместимость с Linux
- **Безопасное обновление поверх существующих версий**: устранена ошибка Linux-инсталлятора при повторной установке поверх ранее установленного OpenFlux (`команда /usr/local/bin/openflux принадлежит другой программе: exit status 1`). Установщик корректно проверяет и обновляет собственные симлинки и бинарники.
- **Совместимость тестовых раннеров**: исправлены тестовые фикстуры bootstrap-установщика для стабильного прохождения CI на `ubuntu-24.04` и средах с внешним размещением рантайма Node.js.
