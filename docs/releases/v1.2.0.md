# OpenFlux Server v1.2.0

Ядро обновлено до официального релиза OpenFlux v0.17.1 (коммит `f492a1a33b7581ad8f88118f97e0b866adda3cdc`). Версия веб-панели и CLI повышена до v1.2.0. Все локальные серверные патчи и интеграции Zen Server проверены и сохранены.

### Основные изменения и новый функционал:

- **Обновление ядра OpenFlux до v0.17.1**:
  - **Telemost SFU**: полнопоточный размер слота 1920×1080 по умолчанию с приростом скорости передачи до 2.44x; поддержка параметров `slot_w`/`slot_h` в настройках транспорта.
  - **Безопасность сессий (--refuse-peer-login)**: добавлена опция запрета передачи cookie аккаунтов клиентами в туннеле для предотвращения перехвата и подмены учетных записей сервера; доступно управление через чекбокс в веб-панели и CLI.
  - **Адаптивный MTU и WebRTC/SCTP**: несущие объявляют размеры пакетов и пакетирования (`CarrierMTU`); TUN интерфейс и WebRTC адаптируются под лимиты активных несущих.
  - **Пиннинг несущих (Carrier Pinning)**: возможность фиксировать активную несущую в обход приоритетов.
  - **Оптимизация Avito ShareDB**: регистрация комнат, обновленный User-Agent для исключения 403, автоподключение и синхронизированный backoff при лимитах 429.
  - **Direct транспорт**: оптимизация TCP буферов (4 МиБ send buffer вне Linux), ускоренная передача соединений и алгоритм контроля перегрузок Reno.
  - **Фиксация контекста KDF (Context Pinning)**: единый детерминированный контекст KDF по умолчанию с поддержкой legacy-альтернатив для совместимости с ранними клиентами.

- **Веб-панель и CLI v1.2.0**:
  - Поддержка управления опцией `--refuse-peer-login` в настройках туннеля.
  - Поддержка параметров `slot_w`, `slot_h`, `prefer` в JSON-параметрах транспортов.
  - Обновлены версии ядра и панели в статусах настроек, заголовках и ассетах.
  - Полная обратная совместимость сохраненных туннелей и реквизитов доступа.

Сборка установщиков включает семь целевых платформ: Windows (amd64, arm64, 386) и Linux (amd64, arm64, 386, armv7).
